Authentix is a static landing page concept designed to help thrift shoppers learn how to identify authentic branded products and shop second-hand items with more confidence.

## Overview

The landing page presents Authentix as a concept for thrift shoppers, featuring sections about product authenticity, brand details, and safe thrifting tips.

## Design Sections

- QR & Barcode Verification concept
- Authenticity Education
- Safe Thrifting Tips

## Built With

- HTML
- CSS

## Project Scope

This project is a static landing page created to explore the visual design and presentation of an authenticity-checking concept. The features presented on the page are conceptual and are **not currently functional**.
